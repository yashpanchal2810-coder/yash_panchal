Academic management system · PHP + MySQL

FacultyERP

A web-based college ERP application developed to streamline academic and administrative operations through separate role-based portals for Principal, HOD, Teachers, and Students. The system connects attendance, timetable management, student materials, academic records, reporting, and user management in one platform.

PHP HTML, CSS & JavaScript MySQL Database Role-based authentication CRUD workflows

Project overview

Connecting faculty, students, and administration through one academic workflow.

Developed using PHP, MySQL, HTML, CSS, and JavaScript, this project gave me practical experience in full-stack web application development, database integration, authentication, role-based access control, CRUD operations, and designing workflows for different users within an educational institution.

Role-based access

Create separate workflows for Principal, HOD, Teacher, and Student accounts so each user can access the modules relevant to their responsibilities.

Attendance management

Teachers can select a course and date, view enrolled students, and record attendance for academic monitoring and reporting.

Timetable management

Assign courses to weekly days and time periods to organize faculty teaching schedules.

Academic materials

Teachers can provide course-related learning materials while students browse resources organized for their academic requirements.

Academic administration

Give administrators and HODs centralized tools to manage courses, students, faculty, academic information, and department activities.

Reports and monitoring

Generate attendance and academic reports to give management and faculty better visibility into student activity.

Multi-user authentication

Provide separate login experiences with role-based permissions that control access to different modules and functionality.
