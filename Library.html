Library Management System

A web-based library management application developed as my BCA final year project. The system digitizes library operations including book inventory, member registration, book search, author and publisher management, book issuing/returning, and defaulter tracking.

Project overview

Turning daily library work into a connected workflow.

Developed using ASP.NET and C#, the project gave me practical experience in web application development, database integration, CRUD operations, and designing real-world management workflows.

Book inventory

Organize and maintain book records with author and publisher information.

Member registration

Capture member details and manage account status in one place.

Search and discovery

Help users locate books by title, author, genre, or keywords.
